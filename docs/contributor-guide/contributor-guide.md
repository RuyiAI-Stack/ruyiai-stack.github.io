# 贡献与合作指引

**参与 RuyiAI，一起建设开放、共享的 RISC-V AI 生态。**

无论你希望提交第一份开源贡献、与社区开展技术合作，还是通过实习参与真实项目，我们都欢迎你的加入。你可以根据自己的兴趣、经验和时间安排，选择适合的参与方式。

## 一、参与开源贡献

我们欢迎每一位对 RISC-V 与 AI 感兴趣的开发者。代码开发、问题反馈、测试验证、文档改进和技术讨论，都是推动项目进步的重要贡献。

### 从一个开放任务开始

你可以从我们发布的 **Open Task Issue** 中选择感兴趣的任务，逐步熟悉项目与社区协作方式。

1. **找到感兴趣的任务。** 浏览相关仓库的开放任务，了解任务背景、预期目标和相关讨论。

2. **与社区沟通思路。** 在 Issue 下留言，介绍你的想法和参与意愿，与维护者讨论实现方向。

3. **提交你的贡献。** 按照对应仓库的贡献说明开展工作，通过 Pull Request（PR）提交代码、测试或文档，并说明改动内容与验证结果。

4. **跟进评审与反馈。** 与评审者讨论改进建议，完善提交，在协作中加深对项目的理解。

如果这是你的第一次开源贡献，可以从修复一个小问题、补充一个测试或完善一段文档开始。

### 提出你的问题与想法

除了参与已有任务，我们也欢迎你主动提交 Issue，包括：

- **问题反馈：** 报告使用过程中遇到的错误、兼容性问题或性能问题。

- **功能建议：** 提出新的功能需求、应用场景或改进方向。

- **任务提案：** 分享你希望推进的开发工作，与社区共同讨论目标和实现方案。

- **文档与体验改进：** 指出说明不清楚的地方，帮助完善教程、示例和使用流程。

提交 Issue 前，建议先查看已有讨论。反馈问题时，尽量提供运行环境、复现步骤和相关日志；提出新方向时，欢迎说明它希望解决什么问题，以及你对实现方式的初步考虑。

**参与入口：** [访问 RuyiAI GitHub](https://github.com/RuyiAI-Stack)，进入相关项目仓库，查看开放任务或提交 Issue。

## 二、开展开源合作

我们欢迎**开源组织、研究机构、硬件厂商和高校**与 RuyiAI 建立联系，围绕共同关心的技术问题开展合作。

合作可以从一个具体问题、一个硬件平台或一项研究课题开始，例如：

- **开源项目共建：** 围绕 AI 编译器、算子库、运行时及框架适配，共同推进功能开发与项目维护。

- **硬件适配与优化：** 面向 RISC-V 芯片和计算平台，开展软件适配、性能分析与软硬件协同优化。

- **科研与工程协作：** 将研究想法转化为可验证的实现，在真实软件栈和硬件平台上开展实验。

- **人才培养与教学实践：** 围绕开源实习、课程实验和技术交流，共同培养开发者。

## 三、加入学生实习计划

RuyiAI 为学生提供**线下实习岗位与线上开源实习计划**，支持同学们在真实项目中积累工程经验，并根据岗位安排或项目规则获得相应报酬。

### 线下：AI 软硬件协同设计实习生

RuyiAI 依托**中国科学院软件研究所与北京开源芯片研究院的软硬件协同设计合作项目**，提供线下 AI 软硬件协同设计实习岗位。

这一方向适合对 AI 系统软件、编译优化、计算机体系结构和软硬件协同设计感兴趣，希望深入参与研发工作的同学。

你将有机会围绕实际项目需求，参与软件开发、硬件平台适配、性能分析与优化、测试验证等工作，在实践中理解 AI 模型、系统软件与硬件之间的关系。

具体实习方向和工作内容，将结合项目需求与你的兴趣、经验共同确定。

### 线上：开源实习生成长进阶计划

我们希望通过持续的开源实践，帮助同学们从完成第一份贡献开始，逐步参与代码评审和项目维护，成长为能够独立推进工作、支持社区协作的开发者。

#### 起步：OSPP 领航计划，迈出 Contributor 的第一步

如果你希望开始一段系统的开源实践，可以关注 **OSPP 领航计划**。

你可以从 RuyiAI 发布的社区需求方向出发，了解项目、发现问题，提出自己的解决方案，并与社区导师沟通和完善提案。入选后，围绕共同确定的项目目标推进开发、提交成果，积累完整的开源协作经验。

从理解需求、设计方案，到代码实现、测试验证和文档编写，你将在解决实际问题的过程中，逐步成长为项目的 **Contributor（贡献者）**。

**了解项目与参与方式：** [RuyiAI OSPP 页面](https://summer.ospp.ac.cn/org/orgdetail/8d995d4c-b188-4690-9a53-c022dc7c19e3?lang=zh)

具体参与条件、申请流程及项目报酬，请以计划页面公布的信息为准。

#### 进阶：开源维护实习，向 Reviewer 与 Maintainer 成长

在积累一定的贡献经验后，欢迎进一步参与以**代码评审与项目维护**为方向的线上开源实习。

这一阶段，你可以在持续开发的基础上，逐步参与：

- **代码评审：** 理解其他贡献者的设计与实现，从正确性、可读性、测试覆盖和维护成本等方面提供反馈。

- **问题跟进：** 协助复现和分析 Issue，推动问题定位、修复与验证。

- **项目维护：** 改进测试、文档和开发流程，持续跟进相关模块的质量与演进。

- **社区协作：** 参与技术讨论，帮助新贡献者理解项目、完善提交。

我们鼓励同学们通过持续贡献，逐步承担更多责任，向 **Reviewer（代码评审者）** 和 **Maintainer（项目维护者）** 成长。

这份成长来自对项目的深入理解、稳定的贡献和社区协作中建立的信任。我们期待与你一起，把感兴趣的方向做深、做扎实。

## 四、开始参与

你可以从现在最感兴趣的一件事开始：

- **希望参与开源贡献：** 浏览项目仓库，选择一个开放任务，或提交你的问题与想法。

- **希望开展机构合作：** 联系我们，介绍所在机构、关注的技术方向和合作设想。

- **希望申请学生实习：** 联系我们，附上简历或简要自我介绍、相关项目经历或 GitHub 主页，并说明感兴趣的方向、线上或线下意向，以及可投入的时间。
